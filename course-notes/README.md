## Course Plan

| # | Guided reading | Topic |
|---|--------|-------|
| 1 | [Architecture Before Implementation](course-notes1.md) | CPS, MBSE, requirements, C4 and 4+1 views, interfaces, and traceability |
| 2 | [Edge Placement and Distributed Architecture](course-notes2.md) | Placement, communication, service boundaries, Lambda, Kappa, and local deployment |

| 4 | [Decision Architectures and Optional Agentic AI](course-notes4.md) | Rules, control, optimisation, learned components, bounded agent workflows, authority, and human responsibility |

Each chapter is a compact, annotated reading list built around primary research, standards, official documentation, and selected practitioner material. Read the short core route, then follow only the specialist links relevant to the project. The [guided reading index](reading-list.md) suggests an order, while practical guides live in [`../tutorials`](../tutorials/).

The chapters support the architecture work throughout the project. The early review is a checkpoint for feedback, not a freeze: the final architecture must describe the system that was implemented and evaluated.
